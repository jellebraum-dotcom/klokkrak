# Klokkrak online zetten — stap voor stap

Precies zoals bij de Rekenkrak en de Taalkrak: alle bestanden in één map op GitHub Pages.

## 1. Nieuwe repository maken

1. Ga naar [github.com/new](https://github.com/new).
2. Naam: **klokkrak** · Public · geen extra bestanden aanvinken.
3. Klik **Create repository**.

## 2. Bestanden uploaden

1. Klik in de nieuwe repo op **uploading an existing file**.
2. Sleep álle bestanden uit deze map erin (de inhoud, niet de map zelf):
   `index.html`, `leerkracht.html`, `engine.js`, `klokkrak.css`, `qrcode.js`, `jsqr.js`, `sw.js`, `manifest.webmanifest`, de vier `.png`-iconen, `README.md`, `LEESMIJ.md`, `LICENSE`.
3. Klik **Commit changes**.

## 3. GitHub Pages aanzetten

1. Repo → **Settings** → **Pages**.
2. Bij *Source*: **Deploy from a branch** → branch **main**, map **/ (root)** → **Save**.
3. Na een minuutje staat de site op:
   - Leerlingen: `https://oefenkrak.be/klokkrak/`
   - Leerkracht: `https://oefenkrak.be/klokkrak/leerkracht.html`

## 4. Op de iPads zetten

Open de leerlingen-link in Safari → Deel-knop → **Zet op beginscherm**. De app werkt daarna ook offline.

## 5. Zo gebruik je het in de klas

- **Leerkracht**: open `leerkracht.html`, kies graad, onderwerpen en hoeveel hulp er op de wijzerplaat staat → er verschijnt meteen een QR-code.
- **Klassikaal**: kies "👩‍🏫 Samen oefenen" en klik "▶ Start klasoefening" op het digibord. Ideaal voor het dagelijkse klokmoment dat het GO! aanraadt.
- **Zelfstandig**: leerlingen openen de app en kiezen via "Zelf oefenen" hun eigen graad.

## Tips

- **Bouw de hulp op de wijzerplaat af.** Start bij "Uren + minuten", ga daarna naar "Alle uren", dan "12, 3, 6, 9" en tot slot "Geen cijfers". Zo werk je precies volgens de opbouw uit de GO!-visietekst.
- **Begin absoluut, niet relatief.** Voor L1–L2 kies je enkel onderwerpen uit de 1e graad; "kwart over" en "half" horen pas vanaf het derde leerjaar thuis.
- De QR-code verandert live mee met de instellingen — je hoeft niets op te slaan.
